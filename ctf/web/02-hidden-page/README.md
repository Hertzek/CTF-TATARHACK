# Challenge 2: Hidden Page

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Секретная страница |
| **Категория** | Web |
| **Сложность** | Easy |
| **Очки** | 100 |
| **Флаг** | `TATARHACK{h1dd3n_p4g3s_4r3_n0t_s3cur3}` |
| **Порт** | 5002 |

## Описание для участников

> Наш веб-разработчик создал сайт и сказал, что спрятал что-то секретное.
> Интересно, что он имел в виду?
> 
> http://localhost:5002

## Подсказки

1. Попробуй угадать URL скрытой страницы
2. Какое слово означает "секрет" на английском?
3. Попробуй `/secret`

## Способ решения

1. Открыть http://localhost:5002
2. Заметить, что на главной странице ничего интересного
3. Попробовать стандартные скрытые пути: `/admin`, `/secret`, `/hidden`
4. Перейти на http://localhost:5002/secret
5. Получить флаг!

## Образовательная цель

Показать, что скрытые страницы без защиты — не безопасность. 
Познакомить с концепцией directory enumeration и важностью авторизации.
