## Способ решения

1. Открыть страницу http://localhost:5001
2. В поле логина ввести: `' OR 1=1 --`
3. В поле пароля ввести любое значение
4. Нажать "Войти"
5. Получить флаг!

### Почему это работает?

Оригинальный SQL-запрос:
```sql
SELECT * FROM users WHERE username='' AND password=''
```

С инъекцией становится:
```sql
SELECT * FROM users WHERE username='' OR 1=1 --' AND password=''
```

- `OR 1=1` — условие всегда истинно
- `--` — комментарий, остальная часть запроса игнорируется

## Образовательная цель

Показать детям, почему нельзя вставлять пользовательский ввод напрямую в SQL-запросы. 
Объяснить важность экранирования и параметризованных запросов.
