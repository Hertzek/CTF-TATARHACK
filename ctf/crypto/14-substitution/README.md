# Challenge 14: Substitution Cipher

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Подстановка |
| **Категория** | Crypto |
| **Сложность** | Medium |
| **Очки** | 200 |
| **Флаг** | `TATARHACK{subst1tut10n_c1ph3r}` |

## Описание для участников

> Зашифрованное сообщение использует шифр подстановки.
> Каждая буква заменена на другую.
> К счастью, у нас есть частичная таблица подстановки!
>
> Зашифрованный текст: `ZCZCKXZFP{WQJWZ1ZQZ10G_F1SX3K}`
>
> Частичная таблица:
> ```
> A → Z
> B → J
> C → F
> H → X
> K → P
> ```

## Подсказки

1. Используй известные пары для восстановления таблицы
2. TATARHACK должен превратиться в ZCZCKXZFP
3. Попробуй угадать остальные буквы

## Способ решения

### Анализ
```
T → Z
A → Z (дано)
T → Z
A → Z
R → K
H → X (дано)
A → Z
C → F (дано)
K → P (дано)
```

Полная таблица подстановки:
```
A→Z, B→J, C→F, D→?, E→?, F→?, G→?, H→X, I→1, K→P, L→?, 
N→G, O→0, P→S, R→K, S→W, T→Z, U→Q
```

### Python решение
```python
cipher = "ZCZCKXZFP{WQJWZ1ZQZ10G_F1SX3K}"

# Таблица обратной подстановки (cipher → plain)
reverse_table = {
    'Z': 'T', 'C': 'A', 'K': 'R', 'X': 'H', 'F': 'C', 'P': 'K',
    'W': 'S', 'Q': 'U', 'J': 'B', 'G': 'N', 'S': 'P', '1': 'I',
    '0': 'O', '3': 'E', '_': '_', '{': '{', '}': '}'
}

plaintext = ''.join(reverse_table.get(c, c) for c in cipher)
print(plaintext)
```
