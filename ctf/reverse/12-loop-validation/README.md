# Challenge 12: Loop Validation

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Посимвольная проверка |
| **Категория** | Reverse |
| **Сложность** | Medium |
| **Очки** | 200 |
| **Флаг** | `TATARHACK{l00p_ch3ck}` |

## Описание для участников

> Программа проверяет каждый символ пароля отдельно.
> Анализируй условия!
>
> Файл: `loop_check`

## Подсказки

1. Программа проверяет каждый символ по отдельности
2. Посмотри на условия в цикле
3. Каждый символ сравнивается с определённым значением

## Способ решения

### В Ghidra
1. Найти цикл проверки в main()
2. Увидеть сравнения вида: `input[0] == 'T'`, `input[1] == 'A'`...
3. Собрать пароль посимвольно

### Через ltrace
```bash
ltrace ./loop_check
# При каждом неверном символе видно какой ожидался
```

## Компиляция
```bash
gcc -o loop_check loop_check.c
```

## Образовательная цель

Показать анализ циклов и условий в программах.
