## Описание для участников

> Программист решил "защитить" свою программу, добавив кучу бесполезного кода.
> Но настоящая проверка всё ещё где-то там...
>
> Файл: `obfuscated`

## Подсказки

1. Большинство кода — мусор
2. Ищи реальные операции сравнения
3. Обрати внимание на функцию real_check

## Способ решения

### В Ghidra
1. Открыть и найти main()
2. Заметить много бессмысленных вычислений
3. Найти вызов real_check()
4. Проанализировать реальную проверку

```c
// Реальная проверка простая:
strcmp(input, "hidden_key")
```

## Компиляция
```bash
gcc -O0 -o obfuscated obfuscated.c
```

## Образовательная цель

Научить отличать важный код от "шума".
Показать, что обфускация затрудняет, но не делает невозможным анализ.
