# Challenge 3: Password Check

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Простой пароль |
| **Категория** | Reverse |
| **Сложность** | Easy |
| **Очки** | 100 |
| **Флаг** | `TATARHACK{str1ngs_4r3_v1s1bl3}` |
| **Пароль** | `secretpass123` |

## Описание для участников

> Мы нашли программу, которая проверяет пароль.
> Если ввести правильный пароль — она покажет флаг.
> Сможешь найти пароль?
>
> Файл: `password_check`

## Подсказки

1. Попробуй команду `strings`
2. Или открой файл в Ghidra
3. Ищи строку, похожую на пароль

## Способ решения

### Метод 1: strings
```bash
strings password_check | grep -i secret
# Или просто
strings password_check
```

### Метод 2: ltrace
```bash
ltrace ./password_check
# Вводим что угодно и видим strcmp с реальным паролем
```

### Метод 3: Ghidra
1. Открыть в Ghidra
2. Найти main функцию
3. Увидеть strcmp с "secretpass123"

## Компиляция
```bash
gcc -o password_check password_check.c
```

## Образовательная цель

Познакомить с базовыми инструментами анализа бинарных файлов.
Показать, что строки в программе можно найти без запуска.
