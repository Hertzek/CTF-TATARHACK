# Challenge 4: Math Check

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Математика |
| **Категория** | Reverse |
| **Сложность** | Easy |
| **Очки** | 100 |
| **Флаг** | `TATARHACK{m4th_1s_3asy}` |
| **Правильный ввод** | `42` |

## Описание для участников

> Эта программа просит ввести число и проверяет его.
> Найди правильное число!
>
> Файл: `math_check`

## Подсказки

1. Открой программу в декомпиляторе
2. Найди условие проверки
3. Какое число умноженное на 2 и плюс 10 даёт 94?

## Способ решения

### Анализ в Ghidra
1. Открыть в Ghidra
2. Найти main()
3. Увидеть: `if (input * 2 + 10 == 94)`
4. Решить уравнение: `x * 2 + 10 = 94` → `x = 42`

### Или через ltrace
```bash
ltrace ./math_check
# Ввести любое число и увидеть вычисления
```

## Компиляция
```bash
gcc -o math_check math_check.c
```

## Образовательная цель

Показать, как анализировать условия проверки в программах.
Познакомить с основами реверс-инжиниринга.
