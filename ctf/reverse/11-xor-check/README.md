## Описание для участников

> Программа проверяет пароль с помощью XOR-шифрования.
> Расшифруй её логику!
>
> Файл: `xor_check`

## Подсказки

1. XOR — обратимая операция: A XOR B XOR B = A
2. Найди ключ XOR и зашифрованные байты
3. Примени тот же XOR к зашифрованным данным

## Способ решения

### В Ghidra
1. Найти массив зашифрованных байтов
2. Найти ключ XOR (0x42)
3. Написать декодер:

```python
encrypted = [0x16, 0x23, 0x16, 0x23, 0x30, 0x2a, 0x23, 0x25, 0x29, 0x1d, 
             0x32, 0x72, 0x30, 0x74, 0x30, 0x77, 0x33, 0x31, 0x77, 0x3f]
key = 0x42

password = ''.join(chr(b ^ key) for b in encrypted)
print(password)  # TATARHACK{x0r_r3v3rs3}
```
