## Описание для участников

> На этом сайте точно есть что-то скрытое от поисковиков.
> Где обычно указывают, какие страницы не нужно индексировать?
>
> http://localhost:5006

## Подсказки

1. Как сайты говорят поисковым роботам, куда не заходить?
2. Проверь стандартный файл для роботов
3. /robots.txt

## Способ решения

1. Открыть http://localhost:5006/robots.txt
2. Увидеть: `Disallow: /super_secret_flag_page`
3. Перейти на http://localhost:5006/super_secret_flag_page
4. Получить флаг!

## Образовательная цель

Объяснить, что такое robots.txt и почему он не обеспечивает безопасность.
Показать, что это публичный файл, который любой может прочитать.
