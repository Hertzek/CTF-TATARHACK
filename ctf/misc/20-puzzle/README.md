# Challenge 20: Puzzle

## Информация для организатора

| Параметр | Значение |
|----------|----------|
| **Название** | Пазл |
| **Категория** | Misc |
| **Сложность** | Hard |
| **Очки** | 300 |
| **Флаг** | `TATARHACK{p1ec3s_t0g3th3r}` |

## Описание для участников

> Флаг был разбит на несколько частей и спрятан в разных файлах.
> Собери все части вместе!
>
> Файлы: part1.txt, part2.txt, part3.txt, part4.txt, hint.txt

## Подсказки

1. Прочитай hint.txt — там указан порядок
2. Каждый файл содержит часть флага
3. Собери части в правильном порядке

## Способ решения

1. Прочитать hint.txt — узнать порядок: 3, 1, 4, 2
2. Собрать части:
   - part3.txt: `TATAR`
   - part1.txt: `HACK{`
   - part4.txt: `p1ec3s_`
   - part2.txt: `t0g3th3r}`
3. Объединить: `TATARHACK{p1ec3s_t0g3th3r}`

```bash
# Или автоматизировать
order=(3 1 4 2)
flag=""
for i in "${order[@]}"; do
    flag+=$(cat part$i.txt)
done
echo $flag
```

## Образовательная цель

Научить анализировать подсказки и собирать информацию из разных источников.
